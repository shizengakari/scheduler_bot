    📅 Googleカレンダー連携設定

    Google Cloud Console で発行した OAuth 2.0 クライアント ID を入力してください。
    入力したクライアントIDはお使いのブラウザ（LocalStorage）にのみ安全に保存されます。

    💡 クライアント ID の取得手順
    1. Google Cloud Console でプロジェクトを作成
    2. 「APIとサービス」→「ライブラリ」から Google Calendar API を有効化
    3. 「OAuth 同意画面」を設定（スコープに .../auth/calendar.events.readonly を追加）
    4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」（ウェブ アプリケーション）を作成
    5. 「承認済みの JavaScript 生成元」に現在のURL（https://shizengakari.github.io や http://localhost:8089 等）を追加
    6. 生成されたクライアント ID を上記に入力して保存
